Application refactor in TypeScript

## Context

Refactor the application to use TypeScript

## Objectives

- Refactor the application to use TypeScript
- Add proper typing to the application
- Add proper error handling
- Add proper logging
- Add proper testing
- Add proper documentation

## General Code Rules
- Use camelCase for variable and function names
- Use snake_case for constants
- Use descriptive variable and function names
- Use native fetch API instead of axios any external libraries
- Use native API instead of any external libraries
- Add correct types for all code
- Use functional React components (don't use classes, don't use React.FC)
